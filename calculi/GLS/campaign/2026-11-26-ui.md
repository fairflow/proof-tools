## 2. The statements

Formulas are `var p`, `⊥`, `A → B`, `□A`. `A.occ p` says that `p` occurs
in `A`. A sequent `X ⇒ Y` is derivable when there is a term of `Fam (X ⇒ Y)`.

**Uniform interpolation for formulas.** For every variable `p` and formula
`A` there are formulas `∃p.A` and `∀p.A`, without `p` and computed from
`p` and `A` alone, such that for every formula `B` without `p`:

    A ⇒ ∃p.A                    A ⇒ B   implies   ∃p.A ⇒ B
    ∀p.A ⇒ A                    B ⇒ A   implies   B ⇒ ∀p.A

**Uniform interpolation for sequents** (Pitts's form, classical). For every
`p` and sequent `Γ ⇒ Δ` there is a formula `E = ∃p(⋀Γ ∧ ¬⋁Δ)` without
`p`, such that for all lists `Υ`, `Ξ` without `p`:

    Γ ⇒ Δ, E                    Γ, Υ ⇒ Δ, Ξ   implies   E, Υ ⇒ Ξ

`∃p.A` is `E` for the sequent `A ⇒`, and `∀p.A := ¬E` for `⇒ A`.

In Lean (each printed by `#statement`, pinned in `GLS/InterpolationTest.lean`):

    def GLS.uniformInterpolation : UniformInterpolation
      where GLS.UniformInterpolation :=
        (p : Nat) → (A : Form) → UIFor p A
    PROVED · axioms: Quot.sound, propext

    def GLS.uniformInterpolationSeq : UniformInterpolationSeq
      where GLS.UniformInterpolationSeq :=
        (p : Nat) → (Γ Δ : List Form) → UISeqFor p Γ Δ
    PROVED · axioms: Quot.sound, propext

The two structures, as written in `GLS/Interpolation.lean`:

```lean
structure UIFor (p : Nat) (A : Form) where
  ex : Form
  all : Form
  ex_free : ex.occ p = false
  all_free : all.occ p = false
  ex_intro : Fam ([A] ⇒ [ex])
  ex_elim : (B : Form) → B.occ p = false → Fam ([A] ⇒ [B]) → Fam ([ex] ⇒ [B])
  all_elim : Fam ([all] ⇒ [A])
  all_intro : (B : Form) → B.occ p = false → Fam ([B] ⇒ [A]) → Fam ([B] ⇒ [all])

structure UISeqFor (p : Nat) (Γ Δ : List Form) where
  E : Form
  free : E.occ p = false
  intro : Fam (Γ ⇒ Δ ++ [E])
  elim : (Υ Ξ : List Form) → (∀ A ∈ Υ, A.occ p = false) → (∀ A ∈ Ξ, A.occ p = false) →
    Fam (Γ ++ Υ ⇒ Δ ++ Ξ) → Fam (E :: Υ ⇒ Ξ)
```

The definitions behind them give `ex := uiExists p A = uiSeq p [A] []`
and `all := uiForall p A = ¬uiSeq p [] [A]`. "Uniform" is visible in the
types: the interpolant is a function of `p` and the sequent, and `B` is
quantified after it.

The semantic content, which carries the proof:

    theorem GLS.uiSeq_iff (p : Nat) (Γ Δ : List Form) (t : Tree) :
      (uiSeq p Γ Δ).holds t = true ↔ ∃ t', Bisim p t t' ∧ (Γ ⇒ Δ).refutedAt t' = true
    PROVED · axioms: Quot.sound, propext

That is, on finite trees (the countermodels of `GLS/Search.lean`), the
interpolant is the bisimulation quantifier:

    t ⊨ ∃p(⋀Γ ∧ ¬⋁Δ)   iff   some t' ≈ₚ t refutes Γ ⇒ Δ

where `≈ₚ` is bisimilarity for the relation "proper descendant", ignoring
`p` (`Bisim p`: related trees agree on every variable other than `p`, and
each proper descendant of one is related to a proper descendant of the
other). And the depth bound, for the interpolant without the shortcut of
§3.5 (`uiSeqRaw`), which is equivalent in GL to `uiSeq` (`uiSeq_equiv_raw`):

    theorem GLS.uiSeqRaw_mdepth (p : Nat) (Γ Δ : List Form) :
      (uiSeqRaw p Γ Δ).mdepth ≤ 2 * (Γ ⇒ Δ).boxes.length
    PROVED · axioms: Quot.sound, propext

where `(Γ ⇒ Δ).boxes` is the list of the distinct boxed subformulas.

## 3. The proof, as found

The order the reviewer asked for was kept: the construction and its proof
below were worked out, mechanised and tested before any paper on uniform
interpolation for GL was opened. The literature agent was started after
`GLS/Interpolation.lean` compiled.

### 3.1 The interpolant

`E(Γ ⇒ Δ; H)` is defined by recursion along the search of
`GLS/Search.lean`. `H` is a list of formulas, read as "every formula of
`H` holds, and so does its box, at every world below". At the top `H` is
empty.

* an axiom (IdP, BotL, IdB):  `E = ⊥`;
* ImpR on `A → B ∈ Δ`:  `E = E(A, Γ ⇒ B, Δ∖(A → B); H)`;
* ImpL on `A → B ∈ Γ`:  `E = E(Γ∖(A → B) ⇒ A, Δ; H) ∨ E(B, Γ∖(A → B) ⇒ Δ; H)`;
* a sequent where only GLR applies, with `Γb` the bodies of the boxed
  formulas of `Γ`:

      E = ⋀{q | q ∈ Γ, q ≠ p} ∧ ⋀{¬q | q ∈ Δ, q ≠ p}
          ∧ (⊤  if Γb ⊆ H,  else  □E(xbox □(H ++ Γb) ⇒ ; H ++ Γb))
          ∧ ⋀{ ◇E(xbox Γ, □C ⇒ C; H) | □C ∈ Δ }

The diamonds are the GLR premises, which the search measure of
`GLS/Measure.lean` already shows to be smaller. The box is the step that
would loop: "every world below can be made to satisfy `Γb`" is again a
sequent with the same boxes. Here `H` stops it. If `Γb ⊆ H` the condition
is already guaranteed by an enclosing box, and `⊤` replaces it. Otherwise
`H` grows strictly. Termination is lexicographic: the number of boxed
subformulas whose body is not in `H`, then the search measure. In Lean
this is structural recursion on two step counters, the outer one for box
steps (`itpK`) and the inner one for the rest (`itpIn`). The inner count
is recomputed from the measure at each box step.

### 3.2 Correctness, semantically

Two lemmas, both by induction on the step counters, with an induction
along the converse of the relation inside:

**(a)** if `t` refutes `Γ ⇒ Δ` and every proper descendant of `t` satisfies
`H`, then `t ⊨ E(Γ ⇒ Δ; H)` (`itpIn_a`, `itpK_a`). The one non-routine
case is a diamond. `□C ∈ Δ` is false at `t`, so `C` fails somewhere below.
By well-foundedness there is a last such world `w`, where `C` fails and
holds at every proper descendant (`last_failure`). `w` refutes the GLR
premise `xbox Γ, □C ⇒ C`. This is Löb's principle used semantically.

**(b)** if `t ⊨ E(Γ ⇒ Δ; H)`, and every proper descendant of `t` is
bisimilar (ignoring `p`) to a tree satisfying `H`, then some tree
bisimilar to `t` refutes `Γ ⇒ Δ` (`itpIn_b`, `itpK_b`). In the critical
case the new tree is built by **flattening**:

    t' := node v' (L₁ ++ L₂)

* `L₁` holds, for every proper descendant `u` of `t`, a tree bisimilar to
  `u` in which `Γb` holds everywhere. For the box case this comes from the
  box conjunct, by induction along the converse of the relation
  (`ctx_build`). For the `⊤` case it comes from the hypothesis on `H`.
* `L₂` holds, for every `□C ∈ Δ`, a tree bisimilar to a proper descendant
  of `t` that refutes the GLR premise for `C`. These come from the diamond
  conjuncts.
* `v'` is the valuation of `t` with `p` reset: true iff `p ∈ Γ`.

Every proper descendant of `t` and every witness becomes a direct child of
the new root. This is legitimate because the relation of GL is
transitive: being a proper descendant of the new root is what matters,
and bisimilarity is for that relation, not for the child relation. Each
copy is chosen independently, so the values of `p` needed by different
subformulas never conflict.

From (a), (b) and `holds_bisim` (a formula without `p` has the same truth
at bisimilar trees), `uiSeq_iff` follows at once. The syntactic statements
follow from soundness and the search's completeness. If `E, Υ ⇒ Ξ` were
refuted at `t`, then by (b) a tree `t' ≈ₚ t` would refute `Γ ⇒ Δ`. `Υ`
and `Ξ` have no `p`, so `t'` would refute `Γ, Υ ⇒ Δ, Ξ`, which soundness
forbids. So the search, which returns a derivation or a refuting tree,
returns a derivation (`famOfNoRefutation`).

### 3.3 The depth bound

Along any branch of the recursion, the set of boxed formulas in the
antecedent never shrinks. A diamond step adds `□C`, which is new, so the
usable boxes fall. A box step makes `H` grow strictly, while the new
antecedent's boxes `□(H ++ Γb)` include the old ones. The quantity

    (usable boxes of Γ) + (boxed subformulas whose body is not in H)

falls by at least one at each modal operator. So the modal depth of
`E(Γ ⇒ Δ; [])` is at most `2n`, with `n` the number of distinct boxed
subformulas (`itpIn_depth`, `itpK_depth`, `uiSeqRaw_mdepth`). The bound was
first tested on 600 random formulas, where it was met with equality on
some, and then proved.

### 3.4 The tests, before the proof

The definition was run before any proof was written, as the method asks
(`GLS/InterpolationTest.lean`):

* known values: `∃p.(p ∧ ¬p) ≡ ⊥`; `∃p.(p ∧ □¬p) ≡ ⊤`;
  `∃p.(□(p → q) ∧ □p) ≡ □q`; `∃p.(□(p ↔ q) ∧ ◇p) ≡ ◇q`;
  `∃p.(□p ∧ ◇¬p) ≡ ⊥`; `∀p.(□p → p) ≡ ⊥`; `∀p` of Löb's axiom `≡ ⊤`;
  `∀p.(q → □p) ≡ q → □⊥`;
* a battery: random formulas over three variables, each checked for
  `A ⇒ ∃p.A`, for `p`-freeness, and for `∃p.A ⇒ B` against every `B` in a
  pool of `p`-free formulas with `A ⇒ B` derivable. Before the proof: 80
  formulas against a pool of 30, then 120 against a pool of 75 (boxes
  nested to depth 3, diamonds, Löb instances); 5,104 consequences in all,
  no failure. The pinned battery in the test file: 40 formulas, the pool
  of 75, 1,527 consequences, no failure.

### 3.5 The simplification (added later the same day, at the reviewer's word)

The reviewer's reply to the first version of this report was "If you can
simplify the interpolant, go ahead". Three changes, each proved not to
alter what the interpolant says. The proofs of §3.2 are the same proofs,
with lemmas for the new constructors.

* **Units are simplified as the formula is built** (`mkAnd`, `mkOr`,
  `mkNeg`, `mkDia`, `mkBox`, `mkConj`, `mkDisj`): `⊥ ∧ X = ⊥`, `⊤ ∧ X = X`,
  `⊤ ∨ X = ⊤`, `◇⊥ = ⊥`, `□⊤ = ⊤`, and their mirror images.
* **Evaluation is lazy** (`orLazy`, `andLazy`, `conjLazy`). The second
  disjunct of ImpL is computed only when the first is not `⊤`, and a
  conjunction stops at its first `⊥`. This changes the time, not the
  formula.
* **A sequent without `p` gives its own formula.** At any node whose sequent
  has no `p`, the interpolant is `⋀Γ ∧ ¬⋁Δ`, whatever the context `H`. In
  (a) a refuting tree makes it true. In (b) the tree itself is the
  bisimilar refuting tree.

The third change can raise the modal depth locally: `⋀Γ` may be deeper
than the bound of §3.3 at that node. So the depth bound is proved for the
interpolant with the shortcut switched off (`uiSeqRaw`, the flag `sh`), and
the two are proved equivalent (`holds_uiSeq_raw`, `uiSeq_equiv_raw`).
`uiSeq`, the one the statements use, has the shortcut.

The effect, measured on the tests' generator:

| formulas | before | after |
|---|---|---|
| 40 of modal depth ≤ 3 (sizes ≤ 14) | largest 549, mean 100 | largest 33, mean 4 |
| the same, shortcut off (`uiSeqRaw`) | — | largest 109, mean 10 |
| `□□q → (¬q → □r)` (no `p`) | 11,010,757 nodes | 10 nodes (itself) |
| 200 of modal depth ≤ 4 (sizes ≤ 24) | did not finish | all done in under 90 s; largest 230,889, mean 1,165 |
| 200 of modal depth ≤ 5 | — | stalls on the fifth, `□(((□(⊥→p)) → □⊥) → ((⊥ → □q) → □□p))` |

On the last formula the search decides `A ⇒` in under a millisecond, while
the interpolant does not finish in a minute. The search may stop at the
first refuted branch. The interpolant must visit every branch, and it
recomputes the same box steps many times: the same `H` arises along many
paths, and nothing is shared. Memoising on `(Γ, Δ, H)` as sets is the
remedy. It was not done, because it would put a table into a function
whose proofs are by structural recursion.

## 5. The literature, read afterwards

The sources and what was read of each are in the agent's notes, condensed
here. READ means the text was read; otherwise the source is cited from an
abstract or from another paper.

* **Shavrukov 1993** (Dissertationes Math. 323). The published text was
  not obtained. The 1991 ILLC report X-1991-03, whose numbering van Gool
  cites, was READ (§0, §2). The proof is semantic: Fine-style normal forms,
  characters of finite treelike models, and an Expansion Lemma (2.10). A
  finite treelike model expands to a model of `B` iff it forces `C`
  (Lemma 2.11; Cor. 2.13, the uniform interpolation lemma for GL). The
  proof of 2.10 **grafts expanded copies of cones directly above the
  root**, using transitivity. This is the closest precedent to the
  flattening of §3.2. Its depth bound is `1 + 3·|F^{n−1}(q)|`, which is
  non-elementary.
* **Visser 1996** ("Uniform interpolation and layered bisimulation",
  Gödel '96). Not obtained. Layered (bounded) bisimulation for IPC, K, GL
  and S4Grz. Kurahashi reports Visser's GL bound as `4n + 1`.
* **Bílková.** Her 2007 Studia Logica paper treats K and T, not GL (the
  brief assumed otherwise). Her Pitts-style proof for GL is in her 2006
  thesis, which was not obtained, and in arXiv:2211.02591 (2022), which
  was READ in full for GL. She uses a calculus with `∧`, `∨`, `¬`
  primitive and a local loop check (the diagonal formula already on the
  left). Her interpolant drops the problematic diamond disjunct when no
  new boxes appear (a truncated `N`). She justifies the truncation by a
  fixed-point lemma proved semantically, and uniformity by induction on
  derivations, using cut admissibility.
* **Férée, van der Giessen, van Gool, Shillito** (IJCAR 2024,
  arXiv:2402.10494; Coq repository `hferee/UIML`), READ. They use **GLS
  itself**, with IdB as initial, as here. They found a gap in Bílková's
  proof: an "observation" about sequents equal as sets, which could not
  be proved. They repaired it by contracting fully before taking canopies
  and GLR premises. Correctness is syntactic (`UI_Three`, by induction on
  derivation height and the measure) and uses the formalised cut
  admissibility. Their GL part is 14,532 lines of Coq (7,583 for the
  calculus and cut elimination, 6,949 for interpolation; the agent's
  count). Their interpolants are computed by extraction to OCaml, and no
  size or depth bound is stated.
* **Kurahashi 2020** (Arch. Math. Logic; uniform *Lyndon* interpolation
  for GL and Grz), abstract and §§1, 5 READ. The proof is semantic, on
  finite transitive irreflexive models, and proves a depth bound of
  `3n + 3`.
* **van der Giessen, Jalali, Kuznets** (WoLLIC 2021; J. Logic Comput.
  2025), §§1–2 READ. Interpolants are computed syntactically and proved
  correct by bisimulation and subtree surgery. This is the same
  architecture as here, but for K, D, T and S5 only, not GL.
* **ten Cate, Kuijer, Wolter** (LICS 2026), §§1–2 READ. For GL only
  non-elementary constructions of uniform interpolants are known.
  Craig interpolants for GL have an exponential lower bound (also
  Papafilippou and Fernández-Duque, CSL 2025). That lower bound carries
  over to uniform interpolants, since a uniform interpolant is a Craig
  interpolant for each implication it serves.
* **Lean.** FormalizedFormalLogic/Foundation has Craig interpolation for
  GL (Maehara's method) and Solovay's theorem, but no uniform
  interpolation. No Lean formalisation of uniform interpolation for any
  modal logic was found. Mechanised uniform interpolation exists in
  Coq/Rocq only (UIML; Férée–Shillito 2026 for KM).

## 6. Comparison: different, shorter, interesting?

**Different.** No source found pairs a Pitts-style interpolant for GL with
a semantic correctness proof. The two published Pitts-style proofs
(Bílková; Férée et al.) prove uniformity by induction on derivations, and
need cut admissibility, height-preserving structural rules and a
fixed-point lemma. Here the uniformity half needs none of these. It needs
only soundness and the search's completeness for finite trees, which this
development already had, and which the search proves with no cut. The
rôle of Bílková's truncated `N` is played by the context `H`. "`⊤` when
`Γb ⊆ H`" is that truncation, justified by the semantics: an enclosing box
has already promised the property at every world below. The flattening
has a precedent in Shavrukov's grafting, which is also semantic, but
Shavrukov's interpolant comes from normal forms over characters, not from
a recursion along a proof search. The gap Férée et al. found in Bílková
(sequents equal as sets) cannot arise here. Nothing is proved by
induction on derivations, so no equality of canopies is ever needed.

**Shorter.** The whole file is 1,354 lines of Lean (983 before the simplification of §3.5), against 6,949 lines of
Coq for the interpolation part of the GL development in UIML. The two are
not alike. UIML proves more about the interpolant's syntax, is written in
a different assistant, and builds its functions by the Braga method. Here
the soundness, completeness and search files are reused and not counted.
But the semantic route is plainly the shorter one for a development that
already has completeness with countermodels as data.

**Interesting.**

1. *A depth bound of `2n`*, PROVED in Lean. The bounds found in the
   literature are `3n + 3` (Kurahashi, for uniform Lyndon interpolants,
   which are a stronger property, so the comparison is not exact), `4n + 1`
   (Visser, as reported) and non-elementary (Shavrukov). The literature
   search for depth bounds was not exhaustive.
2. *The interpolant is computed and its correctness is kernel-checked
   without choice.* The interpolant is an ordinary structural-recursive
   function, and `#eval` runs it.
3. *The bisimulation quantifier, proved for GL on finite trees.* Van Gool
   reports an example of D'Agostino (not read here): over some classes of
   models for which GL is complete, bisimulation quantifiers are not
   definable. So the class matters. The finite trees used here are a class
   where they are definable, as `uiSeq_iff` states.

**What is weak.** In the first version the interpolant was large: there
was no simplification and no sharing, and the ImpL disjunction and the
diamonds duplicated whole subterms. One formula of size 11 with no `p` at
all, `□□q → (¬q → □r)`, gave an interpolant of 11,010,757 nodes. §3.5
simplifies it, and that formula now gives itself. What remains is time,
not size: nothing is shared, and at modal depth 5 one formula does not
finish (§3.5). A size bound was not attempted, and the literature knows
none better than non-elementary.
