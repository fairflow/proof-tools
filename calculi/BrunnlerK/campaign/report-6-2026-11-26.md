# Brünnler's system K: a sequent typed at a shell

Written 2026-11-26 21:35 GMT, by the owner session of this calculus
(Fable 5.2), which did not run the campaign. The task came from the
directing session: `ksearch prove '<sequent>'`, built from the skill's
one bullet for it and then compared with DILL's. Nothing is asked.

## What there is

    ksearch prove [--short] [--ascii] [--deadline=N] '<sequent>'

| file | what |
|---|---|
| `BrunnlerK/Parse.lean` | the reader of a nested sequent from text; a sequent as Lean source (`NSeq.src`) and with the signs of a keyboard (`NSeq.ascii`) |
| `BrunnlerK/Test/Parse.lean` | 118 guards and one run of Lean's own reader over the corpus |
| `Main.lean` | the commands `prove`, `corpus`, `show` |
| `Corpus/prove_corpus.py` | the command on every entry of the corpus |
| `campaign/users-guide.md` | the section "From the command line" |
| `campaign/method-notes.md` | notes 71 to 75 |

The answers and the exit codes: `derivable` (0), with a tree of moves
checked by `treeCert`; `not derivable` (1), with a finite tree, a
countermodel, checked by `noValid` and `noDerivable`; `flag` (3), the
search cut off at the deadline; a text that is not a sequent (2), with
the place of the fault. The file printed ends with the bound
`[propext, Quot.sound]` on its axioms.

## What was checked

1. `lake build` and `lake build ksearch` in `calculi/BrunnlerK`: both
   pass (71 and 101 jobs).
2. **The reader, in the library** (`Test/Parse.lean`, elaborated by the
   build): each of the 22 entries of the corpus is read back from what
   each of the three printers writes, and the 18 entries typed as
   `seq[…]` from their own text; four members of the families further
   on, and three sequents with boxes in boxes; 45 guards for how the
   connectives (20) and the brackets (25) bind; 38 texts refused, each at the
   character named. Lean's own parser and elaborator read what
   `NSeq.src` writes for the 22 entries and 7 more as the sequent it
   was written from.
3. **The command on the corpus** (`python3 Corpus/prove_corpus.py
   --elaborate`): 22 entries, each given in three notations. By
   verdict: **derivable 11, not derivable 11, flag 0, not read 0**.
   Disagreeing with the recorded status: 0. The three notations gave
   the same output for every entry. The file printed for each of the 22
   was elaborated with no error.
4. **One file of each kind, elaborated** (`lake env lean -M 8000`):
   derivable, `[](a -> b) -> ([]a -> []b)`, exit 0, no error; not
   derivable, `[]a -> [][]a`, exit 1, no error; flag, the family
   `nest` at 1024 with `--deadline=1`, exit 3, a file of two comment
   lines, which states nothing and elaborates to nothing.
5. **A certificate altered is refused.** In the file for `[]a -> [][]a`
   the proposition true at the second state was changed (4 to 5). The
   first line of the refusal:

       no_altered.lean:27:38: error: could not synthesize default value for parameter 'h' using tactics

   and the next: `Tactic `decide` proved that the proposition
   noValid.check sequent countermodel = true is false`. The same for a
   tree of moves with its last axiom moved to another proposition
   (`yes_altered.lean:22:2`, the same first line).
6. **Large answers.** `boxAnd 64` (a tree of 2 335 moves) and `nest 256`
   (a sequent nested 256 deep) were typed in through `ksearch show`.
   The first files printed were not elaborated: Lean's limit on
   recursion, as the measurements of 2026-11-23 recorded. With
   `maxRecDepth` raised they stopped at the limit on heartbeats; with
   both lifted they were elaborated, in 17 s and 13 s. The command now
   writes both options into a large file.

## What was not checked

* Nothing larger than those two: where the route ends with the limits
  lifted is not known.
* The flag by a defect (a certificate the compiled check refuses) was
  never produced; `decided` says it should not be.
* The reader on texts outside the tests: there is no fuzzing. A text
  misread gives another question, and the first line shows what was
  read.
* The mark under a fault is placed by counting characters; after a
  barred proposition a terminal may draw it one place off.
* `Corpus/Facts.lean`, the measurements and the tutorial were not run
  again; the build elaborates the first.
