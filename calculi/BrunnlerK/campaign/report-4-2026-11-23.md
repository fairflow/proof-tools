To build and run, in your checkout after a pull:

    (cd ~/Lean/Sources/proof-tools/calculi/BrunnlerK && lake build ksearch && .lake/build/bin/ksearch status)

what the search answered, and whether they agree. Then
`.lake/build/bin/ksearch run boxAnd 32` (or `nest`, `boxOr`, `late`,

## (iv) What differed

1. **From the plan.** The model as data is a finite tree, not a number
   of states with lists of pairs. The search is not the source's.
2. **From the skill's picture of Run.** The skill supposes a producer
   that is not trusted, whose certificate the kernel checks because the
   kernel cannot run the producer. Here the kernel can run it: the
   search is proved and structural. Measured, that direct route was the
   cheaper at every size tried, and it has no certificate to write out.
   The tree of moves remains what gives the proof as an object.
3. **A fault of the search found by measuring.** An instance of the
   axiom with `n` conjunctions beside it had a proof of `2ⁿ⁺¹ − 1`
   steps. Repaired; the measurements are after the repair.
4. **Not measured.** Kernel time apart from elaboration: the column for
   a fact with its certificate has both. The script against the tree,
   on these derivations. Anything on a machine other than this one.
5. **From the skill**: `method-notes.md`, notes 48 to 52.

## (v) What was decided

1. **One producer, the search.** No second producer, no decider, no
   command-line decision tool: no user is known.
2. **The certifier against validity** is `noValid`, on finite trees.
3. **The search looks for an axiom first** (a change to a module of
   Prove; no statement changed).
4. **The route of record for a yes or no**: where only the answer is
   wanted, `decide +kernel` on `Valid Γ`; where the proof is wanted,
   `treeCert.verdict` with the tree from `ksearch`.
5. **Left as found**: the producer's cost on deep nesting. The remedy is
   a search that works in place, with a path, instead of carrying each
   box's proof into its context; that is a new search with new proofs,
   and nobody is waiting for depth 1024.
