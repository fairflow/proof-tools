# `Play/‹Calculus›.lean`: ‹the calculus›, a move at a time

The reviewer's file.  The operator prepared it (‹date›) and does not edit
it again without saying so (`campaign/gates.md`).  It is in no library: no
`lake build` builds it and nothing imports it.  Build the instance first
(`lake build`), then open this file in the editor and type.

`‹tactic›` is `apply_move` of proof-tools, fixed to ‹the calculus›
(declared in `‹Calculus›/Tactic.lean`).  A goal is an attempt
`Att S true j`, shown as `Att S   ‹the judgment›`: ‹how to read it›.

**How to type a line.**

    ‹tactic›             the moves that apply at goal 0; none is made
    ‹tactic› an          those whose names begin with `an`
    ‹tactic› andL        `andL` with its arguments left out: made if only one
                         move of that form applies, else each is offered
    ‹tactic› andL p _    `_` or `?_` for any argument
    ‹tactic› … at 1      the same at goal 1
    ‹tactic› where       the attempt so far, drawn, with goal 0 marked `>`;
                         no move is made

Click an offered line to write it in place of yours.  A line that offers
makes no move.  A line that nothing completes is an error, and so is a
query where no move applies.

**The rules** (the table, with each rule's place in the source, is
`campaign/rule-table.md`; keep it and the source's figure beside this
file):

    ‹each rule in one line: its name here, what it asks, what it leaves›

`all_goals leave_open` at the end of an exercise leaves what is not yet
proved open, without an error.  When a proof is done, delete that line and
change `Att S true` to `Der S`: a derivation, which `famOfDer` carries to a
derivation of the calculus as ‹the source› states it.
